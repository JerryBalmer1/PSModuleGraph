# Assignments: PSModuleGraph

`structure` and `surface` for every subject in `subjects/psmodule-PSModuleGraph.md`.

Two things here are worth reading before trusting the numbers:

**`surface` is assigned only to functions.** A class, an enum, or top-level
script code has no export status. Writing `surface:internal` for them would be
an assignment whose evidence restates the assignment - exactly the
`facet-health:evidence:asserted` failure the meta-facet exists to detect.

**`surface:internal` carries confidence 0.9, not 1.** It rests on an ABSENCE
from `FunctionsToExport`, and an absence is weaker evidence than a presence: a
module may export at runtime through `Export-ModuleMember`, which this module
never evaluates because it never runs the code it analyses. `surface:exported`
and `structure` are both direct observations and carry 1.
